# QubitPath User Guide & Documentation

Welcome to **QubitPath**, an adaptive visual quantum learning lab designed for high-school students, undergraduates, software developers, and educators.

---

## 1. Quick Start Walkthrough

1. **Diagnostic Pre-Assessment:** Navigate to `/pre-assessment` to complete the 8-question baseline diagnostic.
2. **Module 1 (Bits to Qubits):** Explore single-qubit state vectors $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$, normalization $|\alpha|^2 + |\beta|^2 = 1$, and interactive 3D Bloch sphere controls.
3. **Module 2 (Quantum Gates):** Test single-qubit gates ($X, Y, Z, H, S, T$), observe matrix-vector operations, and complete prediction challenges.
4. **Module 3 (Measurement):** Simulate measurement collapse and run repeated shots ($1, 10, 100, 1,000$) to compare theoretical probabilities with empirical histograms.
5. **Module 4 (Entanglement):** Construct the Bell state $(|00\rangle + |11\rangle)/\sqrt{2}$ using $H$ and $CNOT$, observe two-qubit correlation, and review FTL non-communication proofs.
6. **Quantum Playground:** Construct custom circuits on a 1- or 2-qubit canvas, load example circuits, and inspect step-by-step "Why did this happen?" panels.
7. **Post-Assessment & Results:** Complete the final 8-question evaluation to view score gains and misconception reductions.
